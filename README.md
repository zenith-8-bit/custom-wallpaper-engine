# NebulaWall

Lightweight Windows animated wallpaper engine using Python, Tkinter, GLFW, ModernGL and OpenGL 3.3.

## Install

```powershell
python -m pip install -r requirements.txt
python main.py
```

No C++, Visual Studio, Qt, PySide or .NET is required.

The renderer uses the Windows WorkerW desktop layer so the OpenGL surface can sit behind desktop icons.
